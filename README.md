# Xingxing

Game học từ vựng tiếng Trung (HSK 1 – HSK 6) và tiếng Anh (Sơ cấp – Cao cấp) theo kiểu bắn gà.

Gà chạy tới tường thành, chạm vào gà để trả lời câu hỏi (nghĩa, pinyin, hoặc gõ pinyin/chính tả). Trả lời đúng thì đại bác bắn hạ gà, sai hoặc chậm thì gà húc vào tường. Tường hết máu là thua màn.

Toàn bộ game nằm trong `index.html` (không cần build). Mở trực tiếp bằng trình duyệt hoặc deploy tĩnh lên Vercel.
